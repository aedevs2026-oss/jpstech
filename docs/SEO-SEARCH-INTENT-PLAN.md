# Search-intent SEO plan — JAYAM TECH ENGINEERING (JPS)

## Objective
Improve qualified search visibility for product, service, company and local-intent searches, with Chennai / Tiruvottiyur as the verified primary location. Target searchers comparing manufacturers, requesting quotes, researching specifications, or looking for a local fabrication partner.

## Important
Do not place 5,000 phrases in page metadata, visible keyword dumps, or a meta-keywords tag. Google does not use the meta-keywords tag, and unnatural repeated keyword blocks can be treated as keyword stuffing. Search rankings are not guaranteed by any keyword count.

## Page-to-intent mapping
| Page family | Primary user intent | Main topics |
|---|---|---|
| Home | Find a credible local industrial engineering company | industrial fabrication, engineering, Chennai, JPS |
| About | Verify credibility and capability | company profile, workshop, materials, installation scope, actual service area |
| Product index | Compare product lines | dal mill equipment, SS 304 pools, pool ladders, automated gates, boiler/vacuum systems |

| FAQ / future guides | Answer pre-sale questions | specifications, materials, measurement checklist, maintenance, procurement |

## Location plan
Use the factual business address consistently: 117, 1st St, Shanmuga Puram, Tiruvottiyur, Chennai, Tamil Nadu 600057. The existing service narrative says Greater Chennai and Tamil Nadu. Before creating city-specific landing pages, confirm that the company accepts jobs and can install/deliver in each city. Do not create dozens of near-identical location pages just to capture query variants.

## Product and service on-page checklist
- Unique title and description written for each page; mention its actual product/service and differentiator.
- One clear H1; headings organize visible and useful material, not hidden keyword lists.
- Add unique introductory copy explaining applications, materials, options, specification caveats, procurement questions and quote requirements.
- Keep product specs truthful. Replace placeholder dimensions, performance figures, lead times, certifications and testimonials only with verified information.
- Use descriptive internal links from relevant product/service pages to the related detail page and contact page.
- Use image alt text that describes the actual image; do not use alt text as a keyword list.
- Confirm canonical URLs, metadataBase/domain, sitemap and robots output in production.
- Add product/breadcrumb structured data only when the markup accurately describes visible content and does not invent review, rating, price or availability claims.
- Validate with Search Console URL inspection, Core Web Vitals, Rich Results Test and the rendered page.
